# Support files to "Blue Team De La Teoría a la Práctica: Herramientas Open Source"



En este repositorio se encuentran los ficheros utilizados en los diferentes módulos del curso.



* SIEM
* SOAR
* CTI
* FIREWALLS
* IDS-IPS
* WAF
* MAIL PROTECTION
* DNS PROTECTION
* SWG
* VPN



Los ficheros que hay son principalmente, ficheros de tipo docker-compose.yml (con las definiciones para arrancar en Docker los servicios de un determinado producto), ficheros de configuración, scripts y otros ficheros de soporte.
