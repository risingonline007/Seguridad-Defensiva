Support files to Install Safeline with Docker Compose



* Crear en el mismo directorio, donde ubiquemos el docker-compose.yml y el .env, los directorios "logs" y "resources"
* Crear dentro las subcarpetas que se ven en la imagen añadida al repositorio y asegurarse que tengan los permisos adecuados
* En el caso del fichero ".env" asegurarse también que tenga permisos únicamente para root, dado que contiene contraseñas
