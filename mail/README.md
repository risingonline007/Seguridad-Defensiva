Support files to Install iRedMail with Docker Compose



* Se incluye docker-compose.yaml
* Fichero de configuración, con parámetros como las contraseñas (es fichero solo tiene que ser legible por root)
* Crear el directorio "logs" y "data" (donde ubiquemos el docker-compose.yaml)
* Crear los directorios de la imagen adjunta dentro de "data"
* Adjunta imagen con los permisos de las subcarpetas del directorio "data"
